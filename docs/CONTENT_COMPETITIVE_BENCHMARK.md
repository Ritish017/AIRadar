## Part 2: 10-Dimension Editorial Quality Gate

Every platform suite is automatically audited against a rigorous 10-dimension gate before being presented in the workspace:

1. **Fact-Checking & Source Attribution (18% Weight):** Verifies all core claims map directly to primary source documentation (e.g. arXiv URL or official lab release).
2. **Hook Strength (16% Weight):** Audits first 7–9 words for immediate curiosity or empirical stakes.
3. **Information Density (14% Weight):** Requires named benchmarks, token costs, architectural parameters, or verified percentages.
4. **Platform-Native Formatting (12% Weight):**
   * *X (Twitter):* Single punchy post ($\le 280$ chars) + 5-tweet deep dive thread.
   * *LinkedIn:* Clean line breaks, structured takeaways, zero hashtags, professional builder voice.
   * *Instagram:* 6-slide carousel with visual layout directives.
   * *YouTube:* High-retention script with 3-second hook, visual B-roll cues, pacing brackets, and mid-roll retention hooks.
5. **Jargon Suppression (10% Weight):** Automatically scans and penalizes banned terms:
   * `"game-changing"`, `"delve"`, `"unpack"`, `"in the world of"`, `"it's worth noting"`, `"🚀"`.
6. **Contrarian Edge / Original Angle (10% Weight):** Prevents re-stating press releases; articulates who wins, who loses, and the underserved technical consequence.
7. **N-gram Originality & Plagiarism Gate (8% Weight):** Calculates 3-gram word Jaccard similarity against source material. Threshold $< 20\%$ required for safe publication.
8. **Audience Persona Alignment (5% Weight):** Tailored for AI Engineers, ML Researchers, Technical Founders, and Enterprise Architects.
9. **Spam & Clickbait Protection (4% Weight):** Disallows deceptive promises or exaggerated adjectives without supporting data.
10. **Retention Safety Analysis (3% Weight):** Evaluates YouTube script pacing, calculating retention dip risk, cliffhangers, and cognitive load.

## Part 3: Video Prompt Synthesis Compilers

AI Viral Radar V3.1 translates the canonical event and pre-generation brief into production-ready prompts across 3 cutting-edge video synthesis platforms:

### 1. Remotion React Code Generator
* **Output:** Deterministic TypeScript / React code declaring `<Composition>`, `<Sequence>`, CSS transforms, spring physics, and animated benchmark metric cards.
* **Aspect Ratio:** 9:16 vertical (Reels / Shorts / TikTok) and 16:9 widescreen.
* **Pacing:** Framerate synchronized to 30 FPS with precise 90-frame hook windows.

### 2. Gemini Omni Video Prompt Compiler
* **Output:** Highly cinematic, photorealistic multi-modal video prompts specifying 8K photorealism, anamorphic lens optics (35mm / 50mm f/1.4), volumetric cinematic lighting, camera movements (slow dolly push-in, macro pan), and synchronized audio atmosphere.
* **Safety:** Zero generic text overlays; pure photographic and cinematic visual storytelling.

### 3. HyperFrames JSON Workflow Generator
* **Output:** Valid declarative JSON schema specifying scene-by-scene timelines, layer hierarchies, motion curves (cubic-bezier), asset placeholders, audio waveforms, and animated text overlays.

## Part 4: Competitive Content Gap Engine

The Content Gap Engine (`backend/services/trends/content_gap.py`) identifies what existing news coverage is missing:

* **Saturated Angles:** Identifies over-covered themes (e.g., "DeepSeek is cheap", "NVIDIA stock falls", "OpenAI competition").
* **Underserved Angles:** Exposes high-signal technical angles ignored by mainstream press (e.g., "Multi-token speculative decoding latency on FP8 GEMM", "Post-training distillation pipelines without RLHF moats").
* **Explosion Probability:** Employs logistic sigmoid modeling combining independent source velocity and novelty to predict trend continuation probability.
